# Диагностика соединения SpotiRoute

Распакуйте архив целиком и запустите `Run-Diagnostics.cmd`. Проверка занимает примерно минуту. Рядом появится `SpotiRoute-Diagnostics.json` — этот файл нужен для разбора таймаутов установки.

Проверки сравнивают `i.scdn.co` с `image-cdn-fa.spotifycdn.com` на одном IP Fastly, отдельно проверяют Akamai и TLS 1.2. Таймаут соединения увеличен до 12 секунд. В отчёт попадают HTTP-коды, времена curl, отдельная проверка TCP и сообщения TLS, версия curl, имена известных процессов Zapret/VPN и признаки включённого прокси.

Права администратора не требуются. Утилита выполняет четыре запроса к обложке Spotify и сохраняет отчёт; `hosts`, DNS, приложения и службы не меняются. Настройки HTTP-прокси при этих запросах обходятся, как в SpotiRoute. Проверка сертификатов TLS остаётся включённой. Отчёт не включает содержимое `hosts`, имена пользователей, локальные IP-адреса, пути программ, токены или пароли. Автоматической отправки отчёта нет.

На время первого запуска сохраните текущие настройки Zapret/VPN, чтобы отчёт отражал условия, в которых SpotiRoute получил ошибку.

Описание времён TCP и TLS: [документация curl](https://curl.se/docs/manpage.html#-w).
