Первая beta SpotiRoute для Windows.

- Добавлено окно состояния: проверка, пауза, журнал, возврат адресов и удаление задачи.
- Фоновая задача проверяет семь адресов Spotify каждые две минуты. Рабочие адреса сохраняются; замена применяется после повторного сбоя и HTTPS-проверки.
- Адреса CDN получаются через DoH. Общий шлюз управляющих сервисов определяется по опубликованному списку AstraCat и проверяется для всех пяти имён Spotify.
- Перед изменением `hosts` создаётся резервная копия. Посторонние записи сохраняются, конфликт параллельной записи отменяет изменение.

Скачайте `SpotiRoute.exe` или архив, затем нажмите «Установить компонент». После установки окно можно закрыть.

Требуются .NET Framework 4.8, Windows PowerShell 5.1 и системный curl 7.70+. Проверено на Windows 11: сборка, вложенные файлы EXE, 47 тестов ядра и работа фоновой задачи. Полная установка и удаление на чистой VM пока не проверены. EXE не имеет цифровой подписи. Маршрут управляющих сервисов зависит от стороннего шлюза AstraCat.
